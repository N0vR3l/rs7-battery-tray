# RS7 Battery Tray

[English](README.md) | **Русский**

Приложение в системном трее Windows для беспроводной мыши **RS7** (VID `A8A4` / `A8A5`, PID `2255`). Показывает процент заряда на иконке и шлёт уведомление, когда заряд опускается до выбранного порога.

Официальный `DeviceDriver.exe` **не нужен**. Опрос идёт напрямую через Windows HID API.

---

## Как пользоваться

### Что нужно

- Windows 10 или 11
- Python 3.8+ (`python` / `pythonw` в `PATH`)
- Мышь RS7 по 2.4 ГГц (USB-донгл)

### Установка

Из этой папки:

```bat
pip install -r requirements.txt
```

### Запуск

Двойной клик по `run_mouse_battery_tray.bat` или:

```bat
pythonw mouse_battery_tray.py
```

`pythonw` запускает программу без чёрного окна консоли. Если иконки нет — откройте скрытые значки рядом с часами.

Иконка — текущий процент:

| Цвет | Значение |
| --- | --- |
| Зелёный | Больше 35% |
| Жёлтый | 16–35% |
| Красный | 15% и ниже |
| Серый `?` | Мышь не найдена / не отвечает (сон, вынут донгл) |

Наведите курсор — увидите процент и порог уведомления.

### Меню по правому клику

| Пункт | Что делает |
| --- | --- |
| Строка статуса | Текущий заряд и порог (не кликается) |
| **Язык** | **English** или **Русский** — меню, подсказка и тосты меняются сразу |
| **Порог уведомления** | 10 / 15 / 20 / 25 / 30 / 40 / 50% или **Другое…** |
| **Интервал опроса** | 15 с, 30 с, 1 мин, 5 мин |
| **Уведомлять при низком заряде** | Включить / выключить тосты Windows |
| **Запускать с Windows** | Автозапуск для текущего пользователя |
| **Обновить сейчас** | Опросить мышь сразу |
| **Выход** | Закрыть приложение |

Настройки (включая язык) пишутся в `mouse_battery_tray_config.json` рядом со скриптом. При первом запуске интерфейс берёт язык Windows (`ru` или иначе `en`).

### Уведомления

Тост приходит, когда заряд **равен порогу или ниже**. На каждый опрос он не повторяется. Следующий раз — когда заряд снова **поднимется выше порога**, либо примерно через **час**, если так и остаётся низким.

### Автозапуск после переноса папки

Если **Запускать с Windows** уже был включён, выключите и включите пункт снова (или один раз запустите приложение из нового места). Windows запоминает полный путь к `mouse_battery_tray.py`.

## Как устроен код

Два слоя:

1. **`mouse_autonomous_monitor.py`** — поиск мыши и чтение заряда.
2. **`mouse_battery_tray.py`** — иконка, меню, конфиг, уведомления.

### 1. Поиск устройства

HID-интерфейсы перечисляются в реестре:

`HKLM\SYSTEM\CurrentControlSet\Control\DeviceClasses\{4d1e55b2-f16f-11cf-88cb-001111000030}`

Из имени ключа собирается путь `\\?\HID\...`, устройство открывается через `CreateFileW`. `HidD_GetAttributes` оставляет только VID `0xA8A4` / `0xA8A5` и PID `0x2255`. Одна мышь даёт несколько интерфейсов (`MI_00`, `MI_01`, `MI_02`, …).

### 2. Стандартный HID (сначала)

Некоторые мыши отдают **Battery Strength** (`Usage Page 0x06`, `Usage 0x20`) или SMBus **State of Charge** (`Usage Page 0x85`). Это читается через `HidP_GetValueCaps` / `HidP_GetUsageValue`.

**У этой RS7 такого поля нет.**

### 3. Вендорский протокол на `MI_02` (рабочий путь)

Заряд — кастомный отчёт 65 байт на интерфейсе **`MI_02`** (usage page `0xFF01`): input 65 / output 65, **без Report ID**, **без feature-отчётов**.

Порядок:

1. Открыть `MI_02` с overlapped I/O.
2. Сначала повесить `ReadFile` (ответ короткий, поздний read его теряет).
3. `WriteFile` команды, дождаться input-отчёта.

Команда (65 байт):

```text
00 55 30 A5 2E 2E  +  59 нулей
```

- Байт `[4]` — сумма байт `[5..64]` по модулю 256 (здесь `0x2E`).
- Ответ начинается с `00 AA 30`.
- **Процент — байт `[9]`** (0–100).

Команда снята с официального `DeviceDriver.exe` (`WriteFile` / `ReadFile`). Константы — в начале `mouse_autonomous_monitor.py` (`VENDOR_BATTERY_*`).

Отладка монитора (трей это не использует):

```bat
python mouse_autonomous_monitor.py --once
python mouse_autonomous_monitor.py --dump
python mouse_autonomous_monitor.py --send 00 55 30 A5 2E 2E --interface MI_02
python mouse_autonomous_monitor.py --listen 5 --interface MI_02
```

### 4. Трей

`mouse_battery_tray.py`:

- Берёт `read_battery()` из монитора.
- Опрашивает мышь в фоне (`poll_seconds`).
- Рисует иконку 64×64 через **Pillow**.
- Вешает значок в трей через **pystray**.
- Тосты — `icon.notify()`, свой порог — диалог Tk.
- Автозапуск — `HKCU\Software\Microsoft\Windows\CurrentVersion\Run`.

`run_mouse_battery_tray.bat` переходит в эту папку и стартует `pythonw`.
